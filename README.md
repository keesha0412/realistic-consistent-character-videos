# Realistic Narrated Character Videos

A personalized VideoExpress workflow for heartfelt, realistic episodes using up to four consistent recurring characters, a user-supplied script, and Aria narration. Finished videos run **60 seconds to three minutes**.

## Start a new episode

1. Open a new chat and share the [personalized playbook](https://github.com/keesha0412/realistic-consistent-character-videos/blob/main/PLAYBOOK.md).
2. Provide your script or story idea and the character reference images, or identify previously saved references. Specify a desired length and aspect ratio if you have preferences.
3. Ask the assistant to prepare prompts or produce the episode in VideoExpress.

The characters do not speak. The narrator uses **Aria**, with **General** settings. A needed additional character can be generated, saved, and reused. Up to four recurring characters are supported across an episode; the number shown together depends on VideoExpress's current reference controls.

For a reusable starting prompt see [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md). The original examples and reference documents describe an earlier dialogue workflow; use them only for technical UI details that do not conflict with [PLAYBOOK.md](PLAYBOOK.md).

This is a public fork. Do not add private scripts or character reference files unless you intend them to be public.
