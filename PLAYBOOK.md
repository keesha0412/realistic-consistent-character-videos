# Narrated realistic consistent-character videos - personalized playbook

## Purpose and priority
Adapted from https://github.com/ai-playbooks/realistic-consistent-character-videos for Keesha's VideoExpress productions. These instructions override the original playbook's two-character limit, 30-second target, dialogue, lip sync, invented story and adult-only fictional-character defaults. Follow the user's instructions for the current project whenever they differ from these defaults. Never claim a video, reference image, or saved asset exists until verified.

## Starting a project
Accept either a complete script, a partial script, or a story idea. When Keesha supplies a script, use her story, characters, sequence, tone, important wording, and ending as the source of truth; do not replace it with an invented story. Break it into narration and visual beats. Preserve exact narration when she requests exact wording; otherwise suggest necessary changes for timing and obtain her input before changing story meaning. If the script includes spoken dialogue, clarify how she wants it converted into narration; never make characters speak by default. If she asks for a new storyline, develop one.

Ask only for missing essentials: the script or idea, character/reference assignments if unclear, desired length within 60-180 seconds, and format if it cannot be inferred. Default to vertical 9:16 for short-form; change on request. Do not demand Full Access or make unsupported claims about credits. If access or app settings prevent an action, describe the actual blocker.

## Character continuity
Support up to four recurring consistent characters per episode. Use the supplied reference images first; treat separate views of the same person as one character. This project currently has a little girl holding a plush bunny, an adult man in a black jacket, and an adult woman in a black dress, including close-ups for the girl and woman. Do not infer their names or relationships from appearance; map them to roles once the script or Keesha establishes them. Keep the girl visually faithful to her images: her youthful proportions, face, hair and expressive eyes, and her bunny when the scene calls for it. Portray her as innocent, precious and age appropriate; use small natural gestures and sensitive emotional reactions. A heartfelt tone can include drama while honoring the supplied script.

Build a character record for each: name/role if supplied, primary and alternate image references, stable facial features, age presentation, hair, body proportions, default wardrobe, distinguishing props, reference location and approved variations. Maintain consistent identity across shots and episodes; clothing changes only when the story calls for them. Use the references instead of inventing an alternative appearance.

If the storyline needs a character for whom Keesha has not provided an image, create an appropriate realistic reference, save the selected image with a unique character name and the project, and add it to the character record for reuse. Report the actual saved location. Do not silently replace existing references. Reserve a fourth recurring slot when needed. If an episode needs more than four recurring characters, ask which four to prioritize; extras need not recur.

Four characters is an episode-level goal, not a claim that the app accepts four reference images at once. Check the current interface and work within the available reference slots. For scenes with more characters than fit, plan separate close-ups, singles, over-the-shoulder angles, or combine carefully composed images using available tools. Identify exactly which reference applies to each visible character; check each result for likeness, count, wardrobe and spatial continuity. Do not promise perfect consistency.

## Script, narration and pacing
Finished videos must run 60 seconds to 3 minutes, inclusive. Use the requested target; if none is supplied, estimate a suitable duration from the script and confirm only if the choice is material. Divide the episode into scenes and 3-10 second VideoExpress clips (for example, 8-second clips: approximately 8 for a minute, 15 for two minutes, or 23 for three minutes, adjusted after editing). Match the actual narration audio and transitions; avoid long empty pauses. Do not pad or cut a supplied script without discussing changes if it does not fit the target.

Narration is the only speech. In VideoExpress select the narration voice Aria and the General settings as requested; verify current labels and options in the app, and report a blocker if unavailable. Generate or add the narration using the app's available workflow; synchronize the final voice track with the visuals, ensuring the narration is audible and not duplicated. Character dialogue and lip sync are off. Characters convey emotion through facial expression, body language and action, not speaking. Ambient sound or music only if Keesha requests or approves it; keep it beneath narration. Follow her current caption preferences; do not mention captions or subtitles in a VideoExpress prompt when she asks not to.

## Production workflow
1. Read the entire script. Identify emotional arc, essential beats, characters, locations and continuity requirements. Map narration to timestamps and a clip grid; adjust against the real Aria recording.
2. Establish a reusable character bible, wardrobe and location references. Save new reference images and an index where they can be retrieved in later episodes; verify the save and disclose the location. Reuse supplied reference images rather than generating substitutes.
3. Create realistic, cinematic start images, applying the relevant reference images to only the characters visible in each shot. Show spatial relationships and intended directions clearly. Use the app's available realistic style; inspect every accepted reference and image. Keep image prompt enhancement off when it alters the instructions.
4. Produce clips with a clear opening frame, shot size, visible subject, single legible action, camera movement, lighting, and fixed continuity. Use a fresh image when changing framing or reintroducing a character risks identity drift. If chaining, match the actual previous last frame. Refer to people in VideoExpress prompts by visible reference-image descriptors, not their names; include only people visible in the shot.
5. Put exclusions in a [RESTRICTIONS] or [NEGATIVES] section, with 'No' repeated before each prohibition, e.g. 'No dialogue. No lip movement. No extra characters.' Do not include a caption or subtitle restriction if Keesha has asked for no mention of them. Keep narration text outside visual prompts unless the app's narration field specifically requires it.
6. Assemble clips in order and align them to the Aria narration. Trim pauses at clip boundaries without losing story beats; verify final runtime 60-180 seconds, coherent transitions, correct character likeness, and clean audio. Save and export only when requested and supported. Give the actual result or clearly identify unfinished steps.

## Per-episode handoff
Provide the script-to-scene timeline; a reference index showing which images are used; start image and video prompts per clip; narration text and Aria/General voice setting; timing notes; continuity checks; and the status and location of any new assets. If Keesha asks you to operate VideoExpress, use the visible app and verify each material result. Honor requests to preview prompts or approve specific takes. The final episode should feel heartfelt and cinematic while staying faithful to her script.
